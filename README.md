A tiny web tool to find files hidden in open directories using clever Google search operators.  
Type what you’re looking for, pick a file type, and start exploring.  
This tool helps automate the use of widely unknown search engine operators to index interesting directories of software, videos, audio, torrents and more. Enter a search term, pick a corresponding file filter, and fire away. See what you can find!
🔗 **Live Demo:** [Click here](https://subhajit-maji.github.io/open-directory-search/)

---

## ✨ Features
- Quick search using Google dorks (special search operators)  
- Pre-set filters for videos, music, software, torrents, and more  
- Simple, no-nonsense interface  

---

## 🚀 How to Use
1. Open the [demo](https://subhajit-maji.github.io/open-directory-search/).  
2. Enter a keyword (e.g., `lofi beats`).  
3. Select a file type filter and search.  
4. A Google tab opens with results to explore.
